# 接续 26.11.02 之前的实验

更换软件版本前，保留原图、配置、模型保存点和输出目录。以下几类旧产物会影响能否在原处继续。

| 已有产物 | 处理方式 |
| --- | --- |
| 尚未完成的 LSD 或 Mito 预测 | 若旧完成记录没有内容摘要，另用新目录。新记录会校验已完成的数据块及其摘要。 |
| Funke 图数据库 | 旧状态缺少输入或配置标识时，新建数据库和输出。跨节点 worker 使用已认证的 MongoDB，本地 worker 可用回环地址。 |
| 按百分比命名的阈值表 | 阈值和步长须落在 0.01 网格。旧文件名因截断而有误时，重新生成对应 LUT。 |
| 靠近裁剪边缘的 Synful 训练样本 | 默认采样要求上下文落在原图内部。要复现边缘补零，显式设置 `training.allow_context_padding=true`，并核对原图与标签仍覆盖同一物理范围。 |
| 归一化或 CLAHE 切片 | 输出目录与输入分开。整套切片和质控报告会一起写入目标目录。 |
| 替换过程中被中断的旋转结果 | 检查保留的 `.backup-*`。核对新目录后再处理备份。 |

## 当时做了哪些验证

记录包含 400 项测试，其中有一条小体积 MongoDB/Daisy/Funke 流程。检查项涵盖已完成块丢失或被改写、写入与导出被打断、NML 引用、六种轴序排列及稀疏 uint64 标签。这组结果来自本地运行。跨节点运行与突然断电后的恢复需另行验证。[26.11.02 验证记录]({{ "/validation/audit-26.11.02.json" | relative_url }})
