# digspider 实验中的两次返工

第一次出现在第 461 张切片附近，单靠平移对不齐了。第二次出现在训练后，模型把膜两侧也预测成连通。这两个问题发生在同一批 digspider 数据上，定位它们用的是不同的中间结果。

## 切片中途发生了尺度变化

原始数据有 1,006 张 3072 × 2048 的 uint8 TIFF。转为 XYZ 的 Zarr 后，6,329,204,736 个体素逐一与切片相同。TIFF 头记录的 XY 间距为 7.8125 nm，本次采用实验人员确认的 8 nm 各向同性间距，原图没有重采样。

切片经过归一化和 CLAHE（裁剪限值 1.5，网格 16）。从原图就能看到的局部亮斑与竖纹记为采集伪影。到第 461 层附近，切片间出现尺度变化，单用相位相关估计平移无法配准。在不连续处使用受约束的 ORB/RANSAC 后，完成全部 1,006 层的对齐。逐层变换累计到第 0 层，每张原图只插值一次。

## 为什么损失下降，膜两侧却仍连通

以 Spider 权重为起点，在 digspider 标注上微调 LSD 20,000 步、ACRLSD 5,000 步。检查输出时发现，XY 方向的亲和图在膜两侧也偏亮。回查训练样本，旧代码用标签是否非零来判断监督是否有效，结果把边界处理产生的零值排除了。本应作为负边计入损失的位置被忽略，模型预测大片连通也能降低损失。

修正后，由两个端点的掩膜决定这条边能否参与监督，由两个非零实例 ID 是否相等决定它是不是正边。同时补回邻居区域，并跨通道平衡样本权重。在真实标注上，训练目标、掩膜和权重与 Gunpowder 的结果一致。两个模型随后从基线重新训练。

## 重新推理后检查了什么

在 Neuroglancer 中将新的亲和图裁块与其原图叠加，确认空间位置吻合。之后依次检查分水岭片段、合并图、不同阈值的 LUT 和最终标签。排查期间调整过分水岭极性，正式运行采用的是修正监督后重新预测的亲和图。

原始切片、标注和运行记录未随公开文档分发。换用自己的数据时，可参照[切片处理步骤]({{ "/zh/modules/" | relative_url }})和[亲和图审查方法]({{ "/zh/lsd-guide/" | relative_url }})，重新记录坐标和权重。
